# SimpleLawCeylon

## SimpleLawCeylon is a multi-firm web application that lets Sri Lankan law firms manage clients, cases, hearings, documents, deeds and billing in LKR. Each firm pays a subscription and sees only its own data.

### In scope for version one

• Public home page: slides, about, news, contact form.

• Platform admin: firms, subscriptions, law library, default courts, case types and templates

• Firm workspace: clients, conflict check, cases, case history, hearing diary, tasks, reminders

• Documents stored in the firm's own Google Drive, with templates

• Deed register with auto numbering and Land Registry reminders

• Time, expenses, invoices, payments and a client money record, all in LKR

• Printing of client, case and linked law details

• Audit log, email 2FA and data export
